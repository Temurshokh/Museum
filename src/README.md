# VIGER MUSEUM v0.1

Личный минималистичный 3D-музей на HTML, CSS, JavaScript и Three.js. Фотографии и подписи сохраняются в IndexedDB — в хранилище браузера на конкретном устройстве и адресе сайта. В собственную базу данных или на сервер приложения изображения не отправляются.

## Возможности

- 3D-зал с 40 свободными рамками.
- Вид от первого лица.
- ПК: WASD или стрелки для движения, мышь для обзора, `E` для взаимодействия с картиной, `Esc` для освобождения мыши.
- Телефон: виртуальный джойстик для движения, свайп по сцене для обзора.
- Добавление фото из галереи устройства; свободная рамка выбирается автоматически по расстоянию до игрока.
- Название, подпись и удаление картин.
- Локальное сохранение между перезапусками браузера.
- Список картин для быстрого редактирования.

## Запуск на компьютере

**Не открывай `index.html` двойным щелчком.** ES-модули браузера надёжнее работают через локальный HTTP-сервер.

1. Распакуй архив.
2. Открой папку `viger_museum_v0_1` в проводнике.
3. В адресной строке проводника введи `cmd` и нажми Enter.
4. Выполни команду:

   ```bat
   py -m http.server 8000
   ```

   Если команда `py` не работает, попробуй `python -m http.server 8000`.
5. На этом компьютере открой `http://localhost:8000`.

## Открытие на телефоне в той же Wi-Fi-сети

1. Запусти сервер на компьютере командой ниже, чтобы телефон тоже мог к нему обратиться:

   ```bat
   py -m http.server 8000 --bind 0.0.0.0
   ```

2. На компьютере выполни `ipconfig` и найди IPv4-адрес активного Wi-Fi-адаптера, например `192.168.1.10`.
3. На телефоне в том же Wi-Fi открой `http://192.168.1.10:8000`, заменив пример IP на свой.
4. Если Windows спросит о доступе через брандмауэр, разреши доступ для частной сети.

Это локальный сервер для тестирования в домашней сети, а не публичный сайт. Компьютер должен оставаться включённым, пока телефон открывает страницу таким способом.

## Как разместить сайт бесплатно и открывать по ссылке

Для постоянной публичной ссылки проект можно загрузить на бесплатный статический хостинг (например, GitHub Pages). Backend, аккаунты пользователей и серверная база данных не нужны: хостинг отдаёт только статические файлы. Каждое устройство хранит свою отдельную коллекцию в собственном браузере.

## Важные ограничения v0.1

- Three.js загружается с jsDelivr CDN, поэтому при первом запуске нужен интернет. В этой версии вся 3D-библиотека ещё не включена локально в архив; это можно сделать в следующей версии для полностью офлайн-запуска.
- Фотографии не синхронизируются между телефонами и компьютерами. У каждого устройства и каждого адреса сайта своя коллекция.
- Не очищай данные сайта/браузера, если хочешь сохранить музей. Для критически важных фотографий держи обычную резервную копию.
- Картинки уменьшаются до максимальной стороны 1600 px и JPEG-качества, чтобы занимать меньше места.
- Пока реализован один зал и 40 слотов. Мультиплеера, аккаунтов и облачной синхронизации нет.
